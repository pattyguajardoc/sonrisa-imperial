# Sonrisa Imperial

Landing page de la clínica dental Sonrisa Imperial: tratamientos, la clínica,
reserva de horas por WhatsApp y datos de contacto.

- Versión publicada: https://claude.ai/artifact/Dn1syUwafuYgw5BUjTv7DZ
- Todo el sitio está en `index.html` (HTML, CSS y JavaScript en un solo archivo).

## Datos de la clínica

El número de WhatsApp y los horarios de atención para las reservas se cambian
en el objeto `CLINICA`, dentro del `<script>` al final de `index.html`.
La dirección y el teléfono que se muestran están en la sección `#contacto`.
